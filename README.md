# Furrget releases

*Furrget me not!* Signed builds of Furrget by Klora: meeting minutes for Mac, where every point
traces back to what was said. Each release carries the `.dmg` and Sparkle's `furrget-appcast.xml`;
the app checks that feed for updates.

Requires an Apple Silicon Mac on macOS 14.2 or later. Beta builds are not notarized yet: the first time
you open Furrget, go to System Settings → Privacy & Security and click **Open Anyway**.

Source code is private. Releases are published from `kloralabs/furrget`.
