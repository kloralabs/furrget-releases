# Dicto releases

Signed builds of [Dicto](https://dicto.klora.id), meeting minutes for Mac. Each release carries the
`.dmg` and Sparkle's `appcast.xml`; the app checks this feed for updates.

Requires an Apple Silicon Mac on macOS 14.2 or later. Beta builds are not notarized yet: the first time
you open Dicto, go to System Settings → Privacy & Security and click **Open Anyway**.

Source code is private. Releases are published from `klora-ai/dicto`.
